# Direction-Blind Geometry Criteria in 3-D Indoor Localization

Analysis code, normalized data and result tables for the manuscript

> Direction-Blind Geometry Criteria in 3-D Indoor Localization:
> A Large-Scale Audit and a Deployment Screening Rule

submitted to *IEEE Transactions on Mobile Computing*, November 2026.
Status: under review.

## What this repository is

A pre-deployment step reads the rank and condition number of the position information
matrix to decide whether a geometry is identifiable. The manuscript shows that this
readout is direction blind by construction, measures the consequence on 17,800 floor
plans and 4,616,452 ray-tracing links, and proposes a screening rule on the vertical
variance share in place of the pass or fail test.

This repository carries the material behind every number, table and figure in that
manuscript: the normalization pass, the audit scripts, the audit tool, the summary
tables quoted in the text, the table bodies and the console logs of the reported runs.

| Quantity | Value |
|---|---|
| Floor plans | 17,800 |
| Links | 4,616,452 |
| Links of full rank | 99.96 % |
| Links passing a condition-number threshold of 100 | 80.8 % |
| Median effective dimension | 1.46 |
| Median vertical variance share | 0.59 |
| Links where the pass misstates the direction of the burden | 39.8 % |
| Receiver positions in the end-to-end comparison | 33,086 |

## Repository layout

```
.
├── python/                          analysis scripts, one per block of numbers
├── data/
│   └── normalized/
│       ├── links.csv                one row per link, 4,616,452 rows
│       └── scene_meta.csv           one row per floor plan
├── results/                         summary tables quoted in the text
│   ├── e2e_sens_*/                  the four noise settings of Section IV-I
│   ├── tables/                      table bodies as csv and markdown
│   └── logs/                        console logs of the reported runs
└── Qualcomm_Wireless_Indoor_Simulations/
    └── download.log                 record of the source archive retrieval
```

Scripts resolve the repository root from their own location, so they can be called from
any working directory. `normalize_rt.py` is the exception, it reads a relative path and
must be called from the repository root.

## Quick start

Most scripts read the normalized tables and write into `results/`. The full audit over
one split is one command:

```
python python/c2_fullscale_vec.py --split WiPTR/val_grid
```

A split is addressed by the path it occupies below `data/public_raw/`, so the argument
reads `WiPTR/val_grid` and the output reads `results/c2full_WiPTR_val_grid.csv`.
Dropping `--split` walks the whole archive.

The audit tool is the deliverable described in Section III-E. It reads either the native
sparse channel file or the normalized pair, and writes a per-link table, a
machine-readable summary and a human-readable report:

```
python python/identifiability_audit.py --source normalized --outdir results/audit_demo
```

The console output of the run quoted in Section III-E is kept in
`results/logs/audit_demo_normalized.log`. The three output files themselves are produced
by that command and are not shipped, because the run needs `data/normalized/paths.csv`,
which is 171 MB and is regenerated by the normalization pass described below.

Rebuilding the four noise settings of Section IV-I takes the two noise parameters and an
output directory:

```
python python/end_to_end_compare.py --sigma-d 0.05 --sigma-theta-deg 5  --outdir results/e2e_sens_sd005
python python/end_to_end_compare.py --sigma-d 0.20 --sigma-theta-deg 5  --outdir results/e2e_sens_sd020
python python/end_to_end_compare.py --sigma-d 0.10 --sigma-theta-deg 2.5 --outdir results/e2e_sens_th025
python python/end_to_end_compare.py --sigma-d 0.10 --sigma-theta-deg 10 --outdir results/e2e_sens_th10
```

## Two conventions worth stating

The dataset direction runs from receiver to transmitter. Every steering vector is negated
before use, so the unit vector stored in `links.csv` points from the anchor toward the
receiver.

Gain is stored in dB and converted as `10^(g/5)`, not `10^(g/10)`. The divisor follows the
field convention of the source records, and `gain_convention_sensitivity.py` re-runs the
audit with a divisor of 10 and reports the difference.

## What is not in this repository

The raw ray-tracing archive is not redistributed. It is 5.9 GB, it is published under its
own terms, and this repository carries the scripts that read it rather than the archive
itself. Obtain it from the original release and place the trees as the script expects:

```
data/public_raw/Wi3R/{grid,main_5tx,outofdistribution/{fourrooms,scaled,squared}}/dataset_sparse.h5
data/public_raw/WiPTR/{train,train_grid,val,val_grid,val_ood,test}/dataset_sparse.h5
```

The per-path table `paths.csv` is excluded as well, at 171 MB, and is rebuilt by the same
normalization pass with `--with-paths`.

Eight per-link tables are excluded, each holding one row per receiver position and each
regenerated by a single command:

| Excluded table | Size | Rebuild |
|---|---|---|
| `c2full_WiPTR_train.csv` | 601 MB | `--split WiPTR/train` |
| `c2full_Wi3R_main_5tx.csv` | 610 MB | `--split Wi3R/main_5tx` |
| `c2full_WiPTR_val.csv` | 60 MB | `--split WiPTR/val` |
| `c2full_WiPTR_test.csv` | 60 MB | `--split WiPTR/test` |
| `c2full_Wi3R_outofdistribution_fourrooms.csv` | 15.0 MB | `--split Wi3R/outofdistribution/fourrooms` |
| `c2full_Wi3R_outofdistribution_scaled.csv` | 15.0 MB | `--split Wi3R/outofdistribution/scaled` |
| `c2full_Wi3R_outofdistribution_squared.csv` | 15.0 MB | `--split Wi3R/outofdistribution/squared` |
| `c2full_WiPTR_train_grid.csv` | 10.6 MB | `--split WiPTR/train_grid` |

The three splits small enough to ship are kept: `c2full_WiPTR_val_grid.csv`,
`c2full_WiPTR_val_ood.csv` and `c2full_Wi3R_grid.csv`. Every value quoted in the text
survives in the summary tables as well, so a reader who does not rebuild these tables
loses nothing quantitative.

The MATLAB sources that draw Figures 2 to 9 belong to the manuscript submission and are
not part of this repository. `make_paper_figures.py` is an earlier matplotlib version and
is kept for reference only.
